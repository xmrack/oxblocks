The rule set the block was mined under. Monero changes its rules only at a network upgrade, and each upgrade raises the major version. Version 15 arrived in August 2022 and brought ring size 16, Bulletproofs+ and view tags, and version 16 followed a day later. Version 17 brings FCMP++, which replaces rings with a proof over every spendable output, and Carrot, a new way to address outputs. The minor version is the version a miner signals it is ready for. It tracks the major version once an upgrade is live. Neither number names the monerod build that mined the block.

The root of the tree of spendable outputs that this block commits to. An FCMP++ transaction proves that each of its inputs is somewhere in such a tree without saying where, so its anonymity set is every output in it rather than a ring of 16. The root here runs eight blocks ahead: it is the tree as it will stand when the chain is eight blocks past this one, which holds every output up to the previous block that has unlocked by then. A transaction whose reference block is eight above this one was checked against this root. The layer count grows as the tree does, and the proof grows with it.
